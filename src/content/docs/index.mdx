## For agents

1. Fetch [`llms.txt`](/llms.txt) — one line per practice, grouped by domain.
2. Or fetch [`catalog.json`](/catalog.json) and filter by `domain`, `roles`, `stage` or `type`.
3. Fetch the practice's raw `.md` (`md_url`). Act on its **Rules** section.
4. Cite what you followed as `BP-NNNN@x.y.z`.

## For contributors

Propose a practice with the [issue form](/contributing/add-a-practice/), or let a Claude Code agent run the whole route with the [create-practice skill](/contributing/create-practice-skill/).
